# 版式库（27 个：人物段 10＋图解段 17）

时间一律写**全片秒数**（`t`、`t1`、`tl`…）。列表项没写 `t` 的，按段长均分。每个版式在五套风格里都能用，外观随风格变；标「招牌」的是某套风格最有辨识度的版式。

## 按内容挑版式

| 这句话在讲 | 人物段（人在画面里） | 图解段（人进小窗） |
|-|-|-|
| 开场钩子、核心问题 | `title_top` | `bigword_band`、`chapter` |
| 一个关键词、一个公司名 | `title_top`、`sticker`、`plaque` | `band`（带 `badge`） |
| 两个对立的概念 | `side_tags`（全片最多 2 处） | `compare` |
| 2–3 个并列要点 | `chest_cards` | `pip_cards` |
| 3–5 步的链条、成本构成 | — | `chain` |
| 3–4 个追问、清单 | — | `cascade`、`grid4`、`product_row` |
| 一个数字 | `counter` | `bignum` |
| 两个数字对比、增长倍数 | — | `compare` |
| 一组数据的走势 | `gauge`（分层、区间） | `bars`、`tilt_chart` |
| 一个人 | `namecard` | `band`（带 `person`） |
| 新闻、文件、原文 | — | `doc` |
| 一批机构、公司、品牌 | — | `logo_wall` |
| 一个概念的四个面 | `ring` | `ring_full` |

| 结尾 | — | `ending` |
| 实拍场景本身就够 | — | `band`（可加年份标尺、角标、徽章、印章） |

## 人物段（`kind: "host"`）

`title_top` 和 `side_tags` 受人物位置限制：头顶可用高度不到 56px 放不下头顶标题，脸两侧（按推近后算）不到 220px 放不下对立标签。`measure.py` 量完就报全片有多少时间放得下；`draft_plan.py` 给了 `--geom` 会自动避开，开场放不下时改身前卡片。两样都放不下时，人物段用 `chest_cards`、`sticker`、`plaque`、`namecard`、`counter`、`gauge`、`plain` 轮换。

| 版式 | data | 说明 |
|-|-|-|
| `title_top` | `lines: [{spans: [[文字, 类名]…] 或 text＋cls, t, reveal, size}]`（只写一行），`out`（收起时间） | 头顶只放一行核心信息（话题＋数字，或一组对比），问句和口播原话交给字幕。cls 用 T1／T2／TR／TB。写了 `sub` 行不上屏、build 警告；两行以上报错。背后是整条浅压暗（见 SKILL.md 骨架表）。头顶放不下会报错。自动关掉本段推近。 |
| `side_tags` | `left: [中, 英]`，`right: [中, 英]`，`tones: [左, 右]`（info／good／bad／warn／accent），`tl`，`tr`，`push` | 下巴两侧玻璃标签＋屏幕边缘箭头光纹。脸两侧剩不到 220px 会报错。 |
| `chest_cards` | `cards: [{zh, tag, en, t}]`（2–3），`title`（可选，放头顶），`all_on` | 身前一排卡，卡上有小标签，依次点亮。 |
| `namecard` | `name`，`role`，`photo`（素材键），`tag`，`t` | 身前名牌。介绍本人或提到的人物。 |
| `counter` | `label`，`from`，`to`，`prefix`，`suffix`，`decimals`，`plus`，`t`，`dur` | 胸前面板里数字滚动到目标值。**只用核实过的数**。瓷蓝招牌。 |
| `sticker` | `words: [{zh, en, t}]` | 胸前关键词贴纸，后一个替换前一个。 |
| `gauge` | `title`，`sub`，`bottom_label`，`marks: [{label, pos}]`，`fill`，`t`，`side` | 侧边竖向量表，自动放在离脸远的一侧。 |
| `plaque` | `zh`，`en`，`img`，`t` | 下方本风格材质铭牌，字幕挪到铭牌上面。 |
| `ring` | `center: [中, 英]`，`tiles: [[中, 英]×4]`，`t`，`tiles_t` | 胸前环形关系图，字幕挪到头顶。 |

## 图解段（`kind: "graphic"`）

段级字段：`bg`（背景图素材键，可选）、`data.pip`（覆盖小窗：`{shape, x, y, size 或 w/h}`；`false` 不要小窗）、`data.mirror`（强制镜像）。

| 版式 | data | 说明 |
|-|-|-|
| `bigword_band` | `intro: {zh, en}`，`word`，`t`，`band`，`ticker: [词…]`，`cls` | 先出小标题，再砸超大字，下面实拍横条、滚动行情条。炭金招牌。 |
| `band` | `band`，`band2: {key, t}`，`title`，`ruler: {from, to, at, t}`，`dots`，`corner_tag: {zh, en, icon}`，`badge: {zh, t, x, y}`，`person: {name, role, photo, t}`，`stamp: {text, t}` | 标准 B-roll 段。各风格横条位置、小窗、字幕位置不同（卡牌、清单：实拍铺满上半屏、小圆窗挂右上）。 |
| `bars` | `title`，`values`，`labels`，`hi: [起, 止]`，`hi_label`，`hi_t`，`bars_t`，`line: {label, t}`，`q_t`，`note`，`glass` | 柱状图。瓷蓝画在白纸立体面板上（招牌），其他风格深色底＋竖窗。 |
| `pip_cards` | `title`，`cards: [{zh, en, img, t}]`（2–3） | 大竖窗＋另一侧配图卡，依次点亮。镜像随机。 |
| `grid4` | `title`，`tiles: [{key, label, t}]×4`，`all_t` | 2×2 实拍宫格，逐格点亮。 |
| `chain` | `title`，`items: [{zh, en, img, t}]`（3–5），`stamp: {text, en, t}` | 透视编号链＋竖窗，面板轻摆，可盖章。镜像随机。炭金招牌。 |
| `cascade` | `title`，`items: [{zh, en, img, t}]`（3–4），`line: {label}` | 斜向层叠卡片依次落下。镜像随机。 |
| `tilt_chart` | `title`，`values`，`spike: [起, 止]`，`badge: {text, sub, t}`，`future: {label, t}`，`callout: {label, value, t}`，`line_t` | 整体透视倾斜的折线／面积图，事件徽章、未来箭头、数值标注。 |
| `quote` | `lab1, en1, big1, t1, lab2, en2, big2, t2`，`video`，`mode`，`lines: [{text, em, t}]`（block 用） | 按风格的做法：粒子光球（炭金）、品红光带（档案）、引号文字块（瓷蓝）、光球关键词（卡牌）、波普半调（清单）。 |
| `chapter` | `zh`，`en`，`zh2`，`questions: [{text, t}]`，`t`，`mode` | 按风格的做法：纹饰金属字（炭金）、母题图标滚动（档案）、全息环（瓷蓝）、金线黑卡＋章节按钮（卡牌）、光环标题（清单）。 |
| `logo_wall` | `names: [...]`（6–9），`seal: {index, text, t}`，`t` | 机构名牌墙＋印章，竖窗在上。档案招牌。名牌是文字排版，不用别人的 logo 图。 |
| `doc` | `source`，`headline`，`highlight`，`lines`，`t_hi` | 倾斜纸面＋黄色高亮。档案招牌。只放真实原文或本人说的话。 |
| `compare` | `title`，`a: {label, value, icon, n}`，`b: {…}`，`t_a`，`t_b`，`mult: {text, t}` | 两块面板对比，图标排数量，最后砸倍数。卡牌是两张圆环卡，清单是左右两色柱。 |
| `bignum` | `pre`，`from`，`to`，`prefix`，`suffix`，`decimals`，`sub`，`t`，`dur`，`light` | 全屏大数字滚动。瓷蓝默认浅色产品白底。 |
| `ring_full` | `center`，`tiles`，`t`，`tiles_t` | 全屏全息环关系图。 |
| `product_row` | `title`，`items: [{label, sub, icon, t}]`（3–4） | 产品排，带透视。 |
| `ending` | `pre: {zh, en}`，`big1`，`t1`，`big2`，`t2`，`t_end`，`name: [名, 后缀]`，`tagline` | 两行收尾金句，最后落署名牌。 |

## 版式变体（同一版式的不同排法）

`data.variant` 指定；不写就按内容或种子自动选：

| 版式 | 变体 | 自动规则 |
|-|-|-|
| `chain` | list 竖向透视面板／steps 横向步骤 | 条目 ≤3 且都 ≤5 个字 → steps |
| `bars` | vertical 竖柱／horizontal 横向排名 | 给了 labels 且有超过 2 个字的类别名 → horizontal |
| `compare` | side 左右／stacked 上下 | 任一数值文字超过 5 个字 → stacked |
| `grid4` | grid 2×2／hero 一大三小 | 第一格写 `"hero": true` 或按种子 |
| `cascade` | diagonal 斜向／zigzag 左右交错 | 按种子 |

人物段另有 `plain`：不加任何包装，只留人物和字幕。全片留几段 plain，节奏才有松有紧（草稿会自动放）。

## 卡牌、清单自己的做法（字段和通用版式不一样的地方）

这两套风格有 6 个版式换了一套搭法（`lib/tujie/forms.py`），写分镜表时按这里填，不用翻代码。没列出的版式和上表一样。

**卡牌 `kapai`**

| 版式 | data | 和通用做法的差别 |
|-|-|-|
| `chapter` | `zh`，`en`，`t` | 金线黑卡，下面一排本片章节按钮：已讲过的变暗，当前章亮起，没讲到的是暗槽（不显示章名）。章名取 plan 的 `chapters`，`zh` 最多约 7 个字。 |
| `chain` | `title: {zh, en}`，`items: [{zh, en, t}]`（3–6），`stamp: {text, en, t}` | 不配图（不用 `img`）。每项是一颗渐变按钮，讲到才从暗槽里亮起；`stamp` 是斜贴的红色小牌，约 7 个字以内。 |
| `compare` | `title: {zh, en}`，`a/b: {label, value}`，`t_a`，`t_b`，`mult: {text, t}` | 两张斜放的圆环卡，圆环按两个数的比例画。`value` 要是数字（「4%」「约1%」），不是数字时圆环几乎是空的，改用 `quote`。不用 `icon`、`n`。 |
| `quote` | `lab1, en1, big1, t1`，`lab2, en2, big2, t2`，`video`（可选背景） | 光球关键词：`lab` 是左上小标签，`big` 在光球里（每行约 6 个字，`|` 换行），`en` 在大字下方。`tone` 是 bad／warn 时，第二个光球变红。 |
| `band` | `band`，`title` 或 `corner_tag: {zh, en}`，`badge: {zh, t, x, y}` | 实拍铺满上半屏（172–1032），左上是分区小标签，`badge` 是金线小黑卡，字幕在实拍下方。写了 `band2`／`person`／`stamp`／`dots`／`ruler` 就退回通用横条。 |
| `counter`（人物段） | `label`，`from`，`to`，`prefix`，`suffix`，`decimals`，`t`，`dur` | 胸前向后倾斜的金线面板，数字滚到目标值。只用核实过的数。 |

**清单 `qingdan`**

| 版式 | data | 和通用做法的差别 |
|-|-|-|
| `chapter` | `zh`，`en`，`t` | 光环标题，背景借最近一段的实拍并虚化。 |
| `chain` | `title: {zh, en}`，`items: [{zh, en, vals, t}]`（3–6），`cols: [{zh, en}]`（可选），`stamp: {text, en, t}` | 对照表：每项一行，格子先是问号，讲到时换成 `vals` 里的内容（不写就是 ✓）。写了 `cols` 就有表头，每行按列给 `vals`。`stamp` 变成表格底部的红条结论。 |
| `compare` | `title`，`a/b: {label, value}`，`t_a`，`t_b`，`mult: {text, t}` | 左右两色铺满，各有一摞横线柱按数值长高，柱顶是数字。`value` 要是数字。 |
| `quote` | `lab1, en1, big1, t1`，`lab2, en2, big2, t2` | 波普半调：网点纸、红色爆炸星、描黑边的大字，字幕区垫一条黑带。 |
| `band` | 同卡牌 `band` | 实拍铺满上半屏，小圆窗在右上。 |
| `chest_cards`（人物段） | `cards: [{zh, en, mark, t}]`（2–4），`label`（可选，表头左边的说明），`title`（可选，头顶一行） | 胸前一行对照表：卡片名做表头，讲到哪格就打上 `mark`（默认 ✓）。 |

## 段落层参数（每个版式都能用）

写在每段的 `data` 里，不写就按文字自动推断（见 SKILL.md 第三节）：

- `*重点词*`：任何显示文字里用星号包住，换强调色；字幕里同词自动变色。
- `tone`：good／bad／warn／info，换这一段的点亮框、小标签、重点词、英文副题颜色。
- `energy`：calm／normal／punch，改动作快慢、缓动幅度和缓动曲线。
- `enter`：blur／stretch／wipe／flip／flicker／rise／zoom，换标题入场。
- `card_enter`：slide／drop／swing／toss／pop／rise，换卡片入场。
- `reveal: "chars"`：逐字出现，用于 `title_top` 的行、`bigword_band` 的大字、`quote` 和 `ending` 的大字；`per` 调每个字的间隔（秒，默认 0.06–0.09）。

同一种版式在一支片里用第二次时，至少换一项段落层参数（入场、色调、节奏之一），不要两段动得一模一样。

## 差异规则（build 会查）

- 图解版式不连用（`band` 除外）。
- 同一版式最多 2 次；`band` 4 次、`quote` 3 次、`chapter` 4 次、`ending` 1 次。
- 至少用一个本风格招牌版式。
- 90 秒以上的片子图解版式至少 5 种。
- `side_tags` 最多 2 处，只用在真正对立的地方。
- 同账号最近 3 支：开场两段版式、收尾＋强调色、母题图标不能重复（需要 `--register` 登记）。
- 至少一半图解段在分镜表里写了段落层参数。
