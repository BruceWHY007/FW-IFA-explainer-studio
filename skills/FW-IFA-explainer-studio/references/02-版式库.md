# 版式库（26 个）

时间一律写**全片秒数**（`t`、`t1`、`tl`…）。列表项没写 `t` 的，按段长均分。每个版式在五套风格里都能用，外观随风格变；标「招牌」的是某套风格最有辨识度的版式。

## 按内容挑版式

| 这句话在讲 | 人物段（人在画面里） | 图解段（人进小窗） |
|-|-|-|
| 开场钩子、核心问题 | `title_top` | `bigword_band`、`chapter` |
| 一个关键词、一个公司名 | `title_top`、`sticker`、`plaque` | `band`（带 `badge`） |
| 两个对立的概念 | `side_tags`（全片最多 2 处） | `compare` |
| 2–3 个并列要点 | `chest_cards` | `pip_cards` |
| 3–5 步的链条、成本构成 | — | `chain` |
| 3–4 个追问、清单 | — | `cascade`、`grid4`、`product_row` |
| 一个数字 | `counter` | `bignum` |
| 两个数字对比、增长倍数 | — | `compare` |
| 一组数据的走势 | `gauge`（分层、区间） | `bars`、`tilt_chart` |
| 一个人 | `namecard` | `band`（带 `person`） |
| 新闻、文件、原文 | — | `doc` |
| 一批机构、公司、品牌 | — | `logo_wall` |
| 一个概念的四个面 | `ring` | `ring_full` |
| 新章节开始 | — | `chapter` |
| 金句、转折 | — | `quote` |
| 结尾 | — | `ending` |
| 实拍场景本身就够 | — | `band`（可加年份标尺、角标、徽章、印章） |

## 人物段（`kind: "host"`）

| 版式 | data | 说明 |
|-|-|-|
| `title_top` | `lines: [{spans: [[文字, 类名]…] 或 text＋cls, t, size}]`，`out`（收起时间） | 头顶 1–3 行。cls 用 T1／T2／TR／TB，`sub` 是强调色小字。头顶放不下会报错。自动关掉本段推近。 |
| `side_tags` | `left: [中, 英]`，`right: [中, 英]`，`tones: [左, 右]`（info／good／bad／warn／accent），`tl`，`tr`，`push` | 下巴两侧玻璃标签＋屏幕边缘箭头光纹。脸两侧剩不到 220px 会报错。 |
| `chest_cards` | `cards: [{zh, tag, en, t}]`（2–3），`title`（可选，放头顶），`all_on` | 身前一排卡，卡上有小标签，依次点亮。 |
| `namecard` | `name`，`role`，`photo`（素材键），`tag`，`t` | 身前名牌。介绍本人或提到的人物。 |
| `counter` | `label`，`from`，`to`，`prefix`，`suffix`，`decimals`，`plus`，`t`，`dur` | 胸前面板里数字滚动到目标值。**只用核实过的数**。瓷蓝招牌。 |
| `sticker` | `words: [{zh, en, t}]` | 胸前关键词贴纸，后一个替换前一个。 |
| `gauge` | `title`，`sub`，`bottom_label`，`marks: [{label, pos}]`，`fill`，`t`，`side` | 侧边竖向量表，自动放在离脸远的一侧。 |
| `plaque` | `zh`，`en`，`img`，`t` | 下方金框（或本风格材质）铭牌，字幕挪到铭牌上面。矿石招牌。 |
| `ring` | `center: [中, 英]`，`tiles: [[中, 英]×4]`，`t`，`tiles_t` | 胸前环形关系图，字幕挪到头顶。 |

## 图解段（`kind: "graphic"`）

段级字段：`bg`（背景图素材键，可选）、`data.pip`（覆盖小窗：`{shape, x, y, size 或 w/h}`；`false` 不要小窗）、`data.mirror`（强制镜像）。

| 版式 | data | 说明 |
|-|-|-|
| `bigword_band` | `intro: {zh, en}`，`word`，`t`，`band`，`ticker: [词…]`，`cls` | 先出小标题，再砸超大字，下面实拍横条、滚动行情条。炭金招牌。 |
| `band` | `band`，`band2: {key, t}`，`title`，`ruler: {from, to, at, t}`，`dots`，`corner_tag: {zh, en, icon}`，`badge: {zh, t, x, y}`，`person: {name, role, photo, t}`，`stamp: {text, t}` | 标准 B-roll 段。各风格横条位置、小窗、字幕位置不同（矿石：横条在上、字幕在下、圆角方窗居中再下）。 |
| `bars` | `title`，`values`，`labels`，`hi: [起, 止]`，`hi_label`，`hi_t`，`bars_t`，`line: {label, t}`，`q_t`，`note`，`glass` | 柱状图。瓷蓝画在白纸立体面板上（招牌），其他风格深色底＋竖窗。 |
| `pip_cards` | `title`，`cards: [{zh, en, img, t}]`（2–3） | 大竖窗＋另一侧配图卡，依次点亮。镜像随机。 |
| `grid4` | `title`，`tiles: [{key, label, t}]×4`，`all_t` | 2×2 实拍宫格，逐格点亮。 |
| `chain` | `title`，`items: [{zh, en, img, t}]`（3–5），`stamp: {text, en, t}` | 透视编号链＋竖窗，面板轻摆，可盖章。镜像随机。炭金招牌。 |
| `cascade` | `title`，`items: [{zh, en, img, t}]`（3–4），`line: {label}` | 斜向层叠卡片依次落下。镜像随机。 |
| `tilt_chart` | `title`，`values`，`spike: [起, 止]`，`badge: {text, sub, t}`，`future: {label, t}`，`callout: {label, value, t}`，`line_t` | 整体透视倾斜的折线／面积图，事件徽章、未来箭头、数值标注。霓虹招牌。 |
| `quote` | `lab1, en1, big1, t1, lab2, en2, big2, t2`，`video`，`mode`，`lines: [{text, em, t}]`（block 用） | 按风格四种做法：粒子光球（炭金）、品红光带（档案）、书法（矿石、霓虹）、引号文字块（瓷蓝）。 |
| `chapter` | `zh`，`en`，`zh2`，`questions: [{text, t}]`，`t`，`mode` | 按风格五种做法：纹饰金属字（炭金）、母题图标滚动（档案）、金框铭牌带问题（矿石）、全息环（瓷蓝）、斜切色块分屏（霓虹）。 |
| `logo_wall` | `names: [...]`（6–9），`seal: {index, text, t}`，`t` | 机构名牌墙＋印章，竖窗在上。档案招牌。名牌是文字排版，不用别人的 logo 图。 |
| `doc` | `source`，`headline`，`highlight`，`lines`，`t_hi` | 倾斜纸面＋黄色高亮。档案招牌。只放真实原文或本人说的话。 |
| `compare` | `title`，`a: {label, value, icon, n}`，`b: {…}`，`t_a`，`t_b`，`mult: {text, t}` | 两块面板对比，图标排数量，最后砸倍数。矿石招牌。 |
| `bignum` | `pre`，`from`，`to`，`prefix`，`suffix`，`decimals`，`sub`，`t`，`dur`，`light` | 全屏大数字滚动。瓷蓝默认浅色产品白底。 |
| `ring_full` | `center`，`tiles`，`t`，`tiles_t` | 全屏全息环关系图。 |
| `product_row` | `title`，`items: [{label, sub, icon, t}]`（3–4） | 霓虹框产品排，带透视。霓虹招牌。 |
| `ending` | `pre: {zh, en}`，`big1`，`t1`，`big2`，`t2`，`t_end`，`name: [名, 后缀]`，`tagline` | 两行收尾金句，最后落署名牌。 |

## 差异规则（build 会查）

- 图解版式不连用（`band` 除外）。
- 同一版式最多 2 次；`band` 4 次、`quote` 3 次、`chapter` 4 次、`ending` 1 次。
- 至少用一个本风格招牌版式。
- 90 秒以上的片子图解版式至少 5 种。
- `side_tags` 最多 2 处，只用在真正对立的地方。
- 同账号最近 3 支：开场两段版式、收尾＋强调色、母题图标不能重复（需要 `--register` 登记）。
