# 参考片拆解

五支财经知识类视频（四支竖版、一支横版），只借方法，不借内容：成片里不出现参考账号的名字、台标、logo，不搬它们的故事、数据和人物。拆法：按场景切点每段抽一帧排总览图，再对重点段每隔 0.13–0.2 秒抽一帧，看入场和缓动。

## 共同骨架（五支都有）

- **人物段**：人物画面占上方约 80%，下方是黑色底座，交界处有台标牌。字幕在人物胸口高度。
- **图解段**：实拍横条（16:9）放在中上部，下面是字幕，人物进小窗（圆窗、圆角方窗或竖窗）。
- **章节卡**：中英双语大字，配题材相关的纹样或实物。
- **缓动**：卡片、小窗、标签一直在轻微浮动；面板、图表有透视并轻摆；没有完全静止的画面。
- **数字**：滚动计数、数量用图标排出来、对比放两块面板。
- **人物介绍**：名牌（照片＋名字＋身份），身份用小字。

## 选部件的原则

- 一支片里每种部件最多用两次；同一个部件不要在相邻两段出现。
- 人物段只用不压脸的部件；参考片里有压到手臂和衣服的，没有压脸的。
- 参考片的动态主要来自三样：入场（每个元素都有）、缓动（一直在动）、点亮（随说话依次亮起）。三样都要有。
