# 分镜表 plan.json

一支片一份。时间都写**全片秒数**（剪辑后的时间，和 captions.json、cuts.json 同一个时间轴）。下面示例里的 `//` 是说明，实际文件是纯 JSON，不能写注释。完整例子见 `examples/demo/plan_demo.json`。

```json
{
  "title": "示例｜一笔钱的三种去处",
  "style": "tanjin",                 // tanjin 炭金 / dangan 档案 / kapai 卡牌 / cilan 瓷蓝 / qingdan 清单（也可以写中文名）
  "accent": "copper",                // 可选，每套 3 种，见 01-五套风格
  "account": "某账号",                // 账号登记用，同账号的片子互相错开
  "seed": 0,                         // 可选；不写按片名生成
  "duration": 40,                    // 成片总长（人声结束后留 1–1.5 秒落版）
  "aroll_duration": 38.6,            // 剪好的人物视频长度
  "captions": "captions.json",       // prep.py captions 的输出（相对本文件）
  "cuts": "cuts.json",               // prep.py cut 的输出：剪辑点，用于跳切推近
  "caption_skip": [],                // 可选：这些时间里不出字幕（开场照常出字幕：头顶标题只是一行关键词，说的话在字幕里）
  "voice_volume": 0.79,
  "host": {"name": "主讲人", "badge": ["主讲人", "后缀"]},
  "chapters": [[0, "问题"], [9, "风险"], [20, "去处"], [31, "用途"]],
  "updates": [
    {"start": 16.5, "end": 20, "label": "最新进展", "label_en": "LATEST",
     "title": "录制之后发生的新事实", "note": "据公开报道 · 出处",
     "stats": [["指标一", "1.0"], ["指标二", "+2%", "up"]]}
  ],
  "motif": ["wallet", "piggy-bank", "trending-up"],
  "keywords": ["三种去处"],          // 可选：字幕里要变色的词（各段文字里 *标出* 的词会自动加进来）
  "no_auto": false,                  // 可选：true 时不按文字自动推断段落层参数
  "segments": [
    {"id": "h01", "kind": "host", "layout": "title_top", "start": 0, "end": 4,
     "data": {"lines": [{"spans": [["一笔钱", "T2"], ["三种去处", "T1"]], "t": 0.1}], "out": 3.8}},   // 头顶只放一行
    {"id": "s02", "kind": "graphic", "layout": "bigword_band", "start": 4, "end": 9, "bg": "bg_demo",
     "data": {"intro": {"zh": "先看一个问题", "en": "A simple question"}, "word": "放*哪里*", "t": 5.2,
              "band": "band_demo", "ticker": ["CASH", "BOND", "EQUITY"],
              "energy": "punch", "enter": "zoom"}}   // 段落层参数：这一段按内容调节奏和入场
  ]
}
```

## 规则

- **段要连续**：一段的 `end` 是下一段的 `start`。人物段（host）是透明叠加层，图解段（graphic）盖住人物。
- **段长**：图解段 3–12 秒；超过 12 秒拆成两段（比如章节卡＋横条）。人物段一般 3–9 秒。
- **开头 4 秒**：人物段＋头顶标题。标题只写一行核心信息（话题＋数字），本人说的整句、问句照常出字幕，不要用 `caption_skip` 跳过。
- **人和图交替**：不要连续 3 段以上图解，也不要连续 3 段以上人物。
- **id**：人物段用 h 开头，图解段用 s 开头，全片唯一。
- **素材键**：`band_x`（横条视频）、`tile_x`（宫格视频）、`full_x`（全屏视频）、`bg_x`（背景图）、`thumb_x`（配图），都由 `prep.py broll／image` 生成并写进导入清单；`om.py import` 之后在 `assets.json` 里。
- **字体、底纹、音效**：`prep.py base` 一次加好，键名固定（font_sm／font_en／font_num／font_sr／font_br、tex_stone／tex_archive、sfx_*）。
- **最新进展卡**：录制后事实有变化（上市了、数据更新了）时用；本人说的话不改。`stats` 最多 2 个，每个是 `[名称, 数值]`，加第三项 `up`／`down` 时数值变绿／红。
- **章节**：3–6 个，章名 2–4 个字。
- **数字时间一律按整片时间写**（不是段内秒数）：落在这一段之外的数字时间，build 直接报错。
- **时间可以写成说话时刻**：任何时间字段写 `"@关键词"` 或 `"@关键词+0.3"`，build 在这一段时间里找这个词被说出来的时刻（先查 `chartimes` 字级时间，再按字幕位置估算）。找不到会报错，换一个本人原话里的词。plan 里写 `"chartimes": "chartimes.json"`（prep.py captions 会生成）。
- **调色**：默认按风格给实拍调色；某段不要就在 data 里写 `"grade": false`，整片不要写在 plan 顶层。
- **段落层参数**：每个图解段按内容设 tone／energy／enter／card_enter／reveal 或用 `*重点词*`，至少一半的图解段要设，对照 SKILL.md 第三节「内容 → 调法」。

## captions.json

`[{"text": "先看一个问题", "start": 4.2, "end": 5.6}, …]`，由 `prep.py captions` 生成。校对稿 `fix.json` 写法：

```json
{"10": "改正后的整句，|这里强制断行", "23": "专有名词改对、数字改对", "drop": [4, 5, 6]}
```

键是转写里的句号（从 0 数），值是改正后的整句（标点会参与断句，`|` 强制断行）。`drop` 是剪掉的句子。没有写进 fix 的句子按字级时间、词边界和停顿自动断。
