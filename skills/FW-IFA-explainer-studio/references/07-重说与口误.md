# 重说和改口：怎么找、怎么剪、留哪一遍

口播原片里最常见、也最容易漏的是**说错重来**：说了半句停住，再从头说一遍。整段转写会把两遍合成一句，只写最后那遍，文字上看不出重复；Agent 又听不到声音，只能靠脚本找。

一条原则：**只留最后一遍完整、准确的说法**，不把几遍的碎片拼成一句；第一遍里后面没再说的铺垫要留。

## 一、怎么找（scripts/edl.py，约 20 秒）

1. **按停顿切成发声段**：人声频段能量高于门限的帧连起来，缝隙不到 0.2 秒的并在一起。轻声的开头和收尾（擦音、气声）往外扩，最多往前 0.6 秒、往后 0.5 秒，能跨过不到 0.12 秒的小低谷。
2. **每段单独转写**：一次调用 whisper-cli 转完全部发声段（2 分钟的片子约 60 段，约 15 秒）。每段只有几个字，模型没机会把两遍合成一句。
3. **比相邻两段的读音**：逐字换成不带声调的拼音再比（`data/pinyin.txt`），转写常把同一个音写成不同的字（他／它、堵／赌）。中间夹着不到 0.5 秒的杂音段，跳过它再比。

| 类型 | 例子（占位内容） | 判据 | 处理 |
|-|-|-|-|
| 改口 | 「这笔钱放在房」→「这笔钱放在存款里」 | 两段开头相同 ≥3 字（前一段不到 1 秒时 2 字也算），前一段只多出 1–2 个字，后一段更长 | 剪掉前一段整段 |
| 改口（整段重说） | 「我们先看一下这个」→「我们先看一下这个数字」 | 前一段 ≥6 字整段出现在后一段开头，只差一两个转写错字 | 剪掉前一段整段 |
| 尾头重复 | 「先看利率，再看期限」→「再看期限和条件」 | 前一段结尾 n 字和后一段开头 n 字读音相同（n≥3；n≥6 时允许一两个错字） | 剪掉前一段结尾这 n 字 |
| 整句重说 | 同一句隔了一两句又说了一遍 | 和后面 3 句里的某一句很像（>0.70） | 删前一句；0.55–0.70 进待听清单 |
| 排比（不剪） | 「比如说房子」→「比如说黄金」 | 开头相同，但前一段多出 3 个字以上、或两段一样长 | 不剪，进待听清单 |

只靠 2 个字或 3 个字判定的，剪了也列进待听清单，交付时请人听一下。

**比文字一律用转写原文**，不用 fix.json 改过的字：字幕改掉重复以后再比，重复就看不见了。

**没装 whisper-cli 时**退回声音信号：一句的语速低于本人中位语速的 6 成，且同一段声音在这句里出现两次，就剪掉第一遍。准确率低，命中的都进待听清单。

## 二、怎么剪：从开口剪到开口

- 剪点一头落在**放弃那遍开口前的停顿**里，另一头落在**最后一遍开口前的停顿**里，两头都不碰任何一个字。
- 尾头重复的剪点，用逐段转写给的逐字时间找到重复那几个字从哪开始，再吸附到前面最近的低谷。
- 句尾按声音找真正说完的地方。转写给的句尾常早 0.1–0.4 秒，按它剪会把最后一个字（尤其是轻声收尾的字）切掉；说完后至少留 0.10 秒，句尾不往回收。
- 句间停顿 ≤0.42 秒不动，更长的压到约 0.26 秒：说完留 0.14 秒，下一句开口前留 0.12 秒。不要压到零，「无缝」听起来是赶。
- 剪完短于 0.3 秒、或几乎没有说话的碎段直接丢掉：留着会在接点多出一次跳帧和咔哒声。

## 三、字幕跟着声音走

- 句子里找到放弃那遍的字，且最后一遍的开头出现在它后面（同一句或后一句）：删掉这几个字。
- 找不到、或最后一遍的开头就在这里（转写把两遍合成一句，只记下了最后一遍）：不删字，把挤进剪掉那段的字挪到最后一遍上。
- 这一句在 fix.json 里有改字时，剪掉的字从改字里也删掉，原文件另存为 `fix.json.bak`，终端会打印改前改后。
- 不能按时间删字：整段转写给的逐字时间常差 0.2–0.5 秒，按时间删会多删或少删一个字。

## 四、接点：声音和画面都要接住

| 层 | 做法 | 在哪 |
|-|-|-|
| 声音 | 每段两头 12 毫秒淡入淡出，拼接处没有咔哒声 | `prep.py cut` |
| 剪点 | 两头都在停顿里，停顿 0.12–0.5 秒；`edl_report.json` 的「接点检查」列出不合格的 | `edl.py` |
| 画面 | 落在人物段中间：跳切推近在接点换一次景别（1.0／1.08），这是口播剪辑遮接点的常规做法。离镜头切换 0.3 秒以内：把镜头切换挪到接点上，让切换本身遮住接点 | `build.py`（读 `joins.json`）、`frame.py` |

不用白闪、闪光一类的效果：在一句话中间闪一下，比跳一下更显眼。

## 五、复核

- **自动复核**：每处重说剪完，把接起来的前后 2.5 秒拼出来再转写一次，确认重复的话只剩一遍、最后一遍开头没缺字。没通过的进待听清单。
- **剪好的人声再查一遍**：`python3 scripts/edl.py --scan 工作目录/om_assets/voice.wav`，有剩下的重说就退出码 1。`recut.py` 最后一步会自动跑。
- **抽帧看接点**：`joins.json` 里 `kind` 是 `retake` 的时间，前后各取一帧，确认画面换了景别或正好是镜头切换。

## 六、改了剪辑表以后：一条命令重跑

```
python3 scripts/recut.py --work 工作目录 --plan plan.json --geom geom.json --out out
```

按顺序重跑剪辑表、剪辑、人声、字幕、配乐（做过才跑）、量人物、搬分镜表时间、导入、构建、检查、查剩下的重说，2 分钟的片子约 2–3 分钟。哪一步失败就停在哪一步。

- 分镜表里写成数字的时间（段起止、章节、各版式的 t／t1…）会从旧时间轴搬到新时间轴：先换回原片时间，再换成新成片时间；落进新剪掉那段的，贴到下一段保留段的开头。写成「@关键词」的不用搬。人声结束后的落版留白长度不变。
- 改之前备份到 `工作目录/_recut/时间/`。
- 剪完不到 0.5 秒的段会被点名，去 plan.json 删掉或并进相邻段。
- 不要手动一步步重跑：漏掉导入就会导出「新画面配旧声音」，手算分镜表时间容易搬错。

## 七、报告里看什么（edl_report.json）

| 字段 | 内容 |
|-|-|
| `找重说的办法` | 逐段转写，或退回声音信号（这时交付前要人听） |
| `自动处理` | 每处剪了什么：类型、放弃那遍、最后一遍、剪掉的原片区间、复核转写和结果 |
| `待听清单` | 只靠两三个字判定的、像排比没剪的、复核没通过的、语速明显偏慢的；交付说明里逐条写时间和原话，请人听 |
| `接点检查` | 不合格的接点：切到了字、停顿太紧或偏长 |
| `fix改字建议` | 已经写回 fix.json 的改字 |
| `输入` | 这次用的转写、原片、fix.json，recut.py 重跑时沿用 |
